# Claudisthenics — Program v0.1 (draft for review)

Base: r/bodyweightfitness Recommended Routine (RR), restructured into Lafay-style
unlockable levels. Low-rep strength progressions (3×5 → 3×8, then harder variant),
not high-rep endurance.

## Session structure (3×/week, non-consecutive days, ~45 min)

1. **Warm-up** (5–8 min): joint circles, band shoulder dislocates, scapular pulls,
   easy squats, wrist prep.
2. **Strength — 3 supersets** (pair two exercises, alternate sets, 90 s rest):
   - Pair 1: *Pull vertical* + *Squat*
   - Pair 2: *Dip* + *Hinge*
   - Pair 3: *Row* + *Push*
   3 work sets per exercise.
3. **Core triplet**: anti-extension / anti-rotation / extension, 3×8–12 (or timed holds).

## Progression rules

- Reps: start each exercise at **3×5**, add reps over sessions up to **3×8** with clean form.
  Timed holds: 3×20 s → 3×60 s.
- **Two-in-reserve rule**: stop every set ~2 reps before failure. Grinding to failure is
  how comebacks end in tendinitis.
- **Level unlock**: when **all six tracks** are at top range, schedule an **unlock test day**:
  hit every top-range target in a single session, prescribed form. Pass → next level.
  Fail → nothing lost, retry next week.
- **Level 0 exception**: minimum 3 weeks regardless of performance. Tendons adapt slower
  than muscles, and 10-years-ago motor patterns come back faster than the tissue does.

## The six tracks

Every level assigns one exercise per track:

| Track | What it builds |
|---|---|
| Pull vertical | pull-up line |
| Row (pull horizontal) | mid-back, posture, ring control |
| Push horizontal | push-up line |
| Dip (push vertical) | dips, triceps/shoulders |
| Squat | quads, knee resilience |
| Hinge | hamstrings/glutes, back insurance |

---

## Level 0 — Réveil *(minimum 3 weeks)*

Goal: reconnect, rebuild tendon tolerance, groove the habit. RPE ≤ 7, always.

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | Dead hang + scapular pulls | 3×20→45 s hang, 3×5 scap pulls |
| Row | Vertical row (rings, body ~30° from upright) | 3×5→8 |
| Push | Incline push-up (table/counter height) | 3×5→8 |
| Dip | Support hold (parallettes or two chairs) | 3×15→30 s |
| Squat | Chair-assisted squat (light hand support) | 3×5→8 |
| Hinge | Glute bridge | 3×8→12 |
| Core | Plank 3×20–30 s · side plank 3×15 s/side · prone back extension 3×8 |

## Level 1 — Fondations

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | Band-assisted pull-up (thick band) | 3×5→8 (+ 60 s dead hang) |
| Row | Incline row (~45° body angle) | 3×5→8 |
| Push | Low-incline push-up (chair height) | 3×5→8 |
| Dip | Negative dip (5 s descent) | 3×3→5 |
| Squat | Full bodyweight squat | 3×5→8 |
| Hinge | Single-leg glute bridge | 3×5→8 /side |
| Core | Hollow tuck hold · side plank · back extension |

## Level 2 — Construction

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | Band-assisted pull-up (medium band) or negatives | 3×5→8 |
| Row | Horizontal row (body horizontal, heels on floor) | 3×5→8 |
| Push | Full push-up | 3×5→8 |
| Dip | Band-assisted dip | 3×5→8 |
| Squat | Split squat | 3×5→8 /side |
| Hinge | Banded Romanian deadlift | 3×8→12 |
| Core | Hollow hold · band Pallof press · arch hold |

## Level 3 — Première Traction *(the milestone)*

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | **Strict pull-up** | 3×3→8 |
| Row | Wide row / feet-elevated row | 3×5→8 |
| Push | Diamond push-up | 3×5→8 |
| Dip | Parallel bar dip | 3×3→8 |
| Squat | Bulgarian split squat | 3×5→8 /side |
| Hinge | Nordic curl negative | 3×3→5 |
| Core | Tucked L-sit · Pallof press · arch raises |

## Level 4 — Consolidation

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | L-sit pull-up (or pull-up + 2 s pause) | 3×5→8 |
| Row | Archer row | 3×4→6 /side |
| Push | Pseudo-planche push-up | 3×5→8 |
| Dip | Ring dip | 3×3→8 |
| Squat | Deep step-up / tempo Bulgarian | 3×8 /side |
| Hinge | Slow nordic negative (8 s) | 3×5 |
| Core | L-sit 3×10–20 s · ring rollout · reverse hyper |

## Level 5 — Envol

| Track | Exercise | Target |
|---|---|---|
| Pull vertical | Archer pull-up | 3×3→6 /side |
| Row | One-arm row progression | 3×3→5 /side |
| Push | Ring push-up / deep pseudo-planche | 3×5→8 |
| Dip | Ring dip, rings turned out | 3×5→8 |
| Squat | Skater squat → pistol progression | 3×3→5 /side |
| Hinge | Band-assisted nordic curl | 3×3→5 |
| Core | L-sit 30 s · dragon flag negative |

## Level 6 — Spécialisation *(endgame, open)*

Pick two specialization tracks and keep the rest in maintenance:
muscle-up · handstand push-up · pistol squat · front lever · one-arm pull-up.
Structure to be designed when someone actually gets here.
